# RP 本地版 2.9

安装包：[dist/RP-local-2.9.apk](dist/RP-local-2.9.apk)。同一包名和签名，可直接覆盖升级旧本地版，不要先卸载。

当前正式版为 **2.9**。后续小改动依次使用 **2.9.001～2.9.599**，末段固定三位；大改动再调整前两段。Android 内部升级序号独立递增，旧版安装包及验证记录保留原编号。

这是以用户提供的 RP-Hub 2.8.80🔔 为起点、合入 2.8.118 修复的本地版。页面和依赖内置，保留本地版界面与功能。

## 1.13 连续返回误退出修复

- 安卓注入的返回脚本改为真正布尔结果。旧脚本返回字符串，WebView 序列化后被回调误判成未处理，导致子页返回仍触发退出计时。

## 1.08 预设分组与独立导入导出

### 图片保存修正

旧保存路径会把 WebView 内部的本地虚拟网址交给安卓 HTTP 下载器；安卓下载器无法读取这种只在 WebView 中存在的文件拦截。0.6 增加受目录限制的 `readImage` 接口，读取已保存图片的字节，再交给原生相册保存，不再用系统下载器访问内部网址。Blob 图片也走字节保存，远端生成结果链接保留原任务的鉴权参数。

远端返回 400 或伪装为图片的错误页面，会显示明确失败提示。保存时禁止请求 `/generate` 和新任务地址，不用重新生图来“修复下载”。本版没有真实手机故障时的网络日志，不能声称所有远端 400 都已解决；实测证据为本地文件、Blob、鉴权缺失模拟及 HTTP 400 模拟。

## 本次改动

1. 将 APK 内置页面及原补丁合成为固定网页源码，不再在启动时按官网变化替换这些页面。
2. Vue、Tailwind、Marked、DOMPurify、Sortable、localForage、JSZip、daisyUI 从安装包读取；0.4 起字体使用设备自带字体。
3. 停用启动时的官网文件刷新和官网版本检查，避免本地版本被在线文件混入。
4. 保留原生文件操作、备份、图片仓库、图片固定、画师串、键盘适配等原实现。
5. 渲染进程死亡后的恢复改为销毁旧 WebView 并重建界面。
6. 移除启动时重复且没有版本判断的 `setForceDark` 调用。
7. 使用独立包名、专用签名和用户提供的图标。

本版沿用原 APK 的安卓外壳；安卓侧保留 smali，并新增 `native/` 下的 Java 文件存储模块。这不是完整的 Android Studio 工程。网页侧为可直接编辑的 HTML/CSS/JS。

## 已完成的验证

- 360、420、1280 像素宽的桌面 Edge 浏览器测试：Vue 挂载、样式生成、主界面显示，无横向溢出及页面脚本错误。
- 420 像素宽下检查角色卡工坊和小说页面的本地加载。
- 阻断所有未映射的外部网页资源；测试用生图及额度接口全部为模拟响应，没有调用真实付费接口。
- 两张图初次提交 2 次生图任务；换画师串、切走再回聊天、页面重载后仍为 2 次。
- 主动重生其中一张，任务累计为 3 次；另一张不变，再次重载没有追加任务。
- APK 内网页及资源文件逐个比对一致，5 个尺寸图标像素一致；具体数量和校验值见 `verification/apk.json`。
- zipalign 和 APK v1/v2/v3 签名验证通过。

**未完成：安卓 16 真机安装与启动、真实模型接口、真实生图服务、用户旧备份迁移及全部功能逐项回归。**

证据保存在 `verification/`。浏览器测试不等于安卓真机验证。

## 文件与维护

- `web/`：初版实际使用的固定网页源码。
- `android/`：安卓外壳的资源、清单和 smali 源码。
- `scripts/build.ps1`：复制网页源码、构建和签名 APK。
- `scripts/verify.cjs`：页面和生图请求次数验证。
- `scripts/check-apk.py`：包名、版本、资源、图标和签名结构检查。
- `scripts/prepare.mjs`：从原 APK 文件初始化网页和安卓改动，**会重建 web 文件；日常修改后不要重复运行它**。
- `reference/RP-Hub/`：本次从 GitHub 获取的官方源码，仅作对照，提交为 `cd8f2a6d599230e8788a1888a478912c6e83d7fe`。
- `.tools/`：本地构建工具及原 APK 副本。
- `.signing/`：本地专用签名，保留用于后续覆盖更新，不包含在 APK 中。

日常改动后，在本机 PowerShell 中执行：

```powershell
& 'D:\大模型用\rp\RP-本地版\scripts\build.ps1'
```
