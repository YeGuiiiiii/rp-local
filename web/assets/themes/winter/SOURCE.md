# 冬至皮肤素材来源

素材来自用户提供的 `Yueyue-Winter-Solstice-v1.0.zip`，包内标注为 Meowa 制作的「玥玥 · 冬至小暖屋」v1.0.0。

- 原始压缩包 SHA-256：`b565f77f930b7dc64162c71b0b31b1600b497b48933134c7d8158e820365dffe`
- 运行时只收录包内 `assets/webp/` 的 42 个文件。
- 原包的素材清单、裁切位置与生成记录保存在仓库 `artwork/winter-solstice-manifest.json`。
- 人物素材沿用包内记录的眼睛高光修正版；软件只负责按日间、夜间切换资源。
