# 配套银月素材

由项目既有 Meowa 流程制作，任务 `job_a9a5c91a297845dea3c55ce99f11ee16`。使用旧银月胸针作为风格参考，提示词保存在 `prompt.txt`。

输出为透明 2048×1536 原图，位于 `sheet/`。`scripts/prepare-glass-art.py` 根据真实透明轮廓提取配套上下角饰、月牙扣、银藤分隔饰和四枚导航图标，去除外围半透明光晕，保留抗锯齿及 8px 透明边距，按比例缩放。

安装包只收录整理后的 WebP，包含 XMP 提示词及同名 JSON 来源记录。旧披风角不再打包，原始历史画稿继续保存在 `artwork/vampire-night-20261106/`。
